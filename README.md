# C Programming Practice 🚀

A collection of basic to intermediate C programs written while learning core programming concepts.

## 📂 Topics Covered
- **Basics & Math:** Area of rectangle, Celsius to Fahrenheit, Compound interest, ASCII values
- **Number Programs:** Prime, Armstrong, Perfect number, Perfect square, Strong number
- **Bitwise Operators:** AND, OR, XOR, NOT
- **Arrays & Strings:** Average of array, Copy array, Bubble sort, Character frequency, Case conversion
